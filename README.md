# Orein Telemetría · descargas

Aquí solo está la **app de Android de Orein Motorsport** ya fabricada (sin código).

- **OreinTelemetria.apk**: la última versión. Descárgala en el móvil Android e instálala.
- **version.json**: la app lo consulta al abrirse para saber si hay una versión nueva y actualizarse.

Desde la versión 2.0, la app avisa sola cuando hay una versión nueva: pulsa **Actualizar ahora** y luego **Instalar**.
